# Codex Buddy 隐私政策

更新日期：2026 年 11 月 10 日

本政策适用于 Codex Buddy 的 macOS、iOS、watchOS 应用，以及小组件和实时活动。开发者为 Weitao Feng；联系入口为 [GitHub Issues](https://github.com/DanielPro0706/Codex-Buddy-macOS/issues)。Codex Buddy 是独立开发的工具，提供 limitis 额度状态、SnapInsert 照片传输和 CloudSpace 自有 gateway 浏览；不是 OpenAI 官方产品。

## 本机处理

Mac 端读取 Codex 的额度状态，包括使用百分比、额度窗口、恢复时间、套餐名称、余额及重置额度的相关信息。Mac App Store 版只读取你通过系统文件选择器授权的 `.codex` 或 `sessions` 文件夹；可在应用设置中移除授权。直接分发版还可使用本机已经登录的 Codex CLI 查询额度；该 CLI 按其自身配置与 OpenAI 服务通信。

直接分发版为调整刷新频率，会在本机检查显示器休眠、电源、合盖、锁屏、屏保状态，以及正常保存的 Codex 会话是否存在正在执行的任务。任务检查解析本地日志的会话和任务生命周期元数据；这些检测结果、进程信息和日志正文不会上传到开发者的推送服务或 CloudKit。App Store 沙盒版不扫描其他进程，也不启动外部 CLI。

应用在设备上保存最近的额度快照、界面偏好、配对地址和随机访问令牌；Mac 版另保存用户选择文件夹的系统授权书签。iPhone 与 Apple Watch 通过 Apple WatchConnectivity 交换额度快照和配对连接信息。小组件使用本机共享缓存；实时活动在系统界面显示选定的额度字段。

应用不会将 Codex 对话正文、提示词、项目文件或本地会话日志上传到 CloudKit、开发者推送服务或配对设备，也不会将 Codex 登录凭据交给这些接收方。

## 设备间同步与服务端处理

| 功能 | 处理的数据及接收方 | 用途 |
| --- | --- | --- |
| 局域网配对 | 配对设备直接访问你 Mac 的本地 HTTP 状态服务，使用随机访问令牌验证请求；响应包含额度快照 | 在同一网络中刷新状态 |
| iCloud 同步 | Apple CloudKit 的用户私人数据库保存最新额度快照、独立推送同步密钥和更新时间 | 同一 Apple Account 下的设备同步 |
| 推送服务 | 开发者运营的 Cloudflare Worker 接收额度快照，以及 APNs token、token 类型、实时活动 ID（如适用）、运行环境和同步密钥；D1 数据库存储密钥的 SHA-256 哈希、最新快照、推送路由信息及更新时间 | 将对应状态更新送达你的设备 |
| Apple 推送 | 开发者服务向 Apple Push Notification service（APNs）发送推送 token 和刷新指令；实时活动推送另包含其显示所需的额度、恢复时间、套餐和重置额度字段 | 后台刷新、小组件和实时活动更新 |

推送服务地址为 `codex-buddy-api.snapenda-daniel.workers.dev`。开发者服务保存的是随机同步密钥的哈希，不是你的 OpenAI 密码；但该哈希可以把额度记录与设备推送 token 关联，因此这些记录并非完全匿名。

Cloudflare 在承载请求时处理网络地址和必要的请求元数据。服务运行诊断可能包括请求路径、时间、响应状态、调用关联信息，以及 APNs 投递失败的类型、环境、状态和原因，用于服务运行、故障排查和安全维护。应用不以这些数据进行广告投放或跨应用跟踪。日志和调用跟踪的保存由服务配置及提供商规则决定；本政策不承诺未经确认的固定保存天数。

Mac 的版本检查会访问 GitHub 的公开 Release API；打开下载、隐私或支持链接时，相应网站会按其规则处理访问请求。Codex Buddy 不向这些网页附加你的额度快照或配对令牌。

Apple 和 Cloudflare 为上述功能提供基础设施，分别适用其 [隐私政策（Apple）](https://www.apple.com/legal/privacy/)、[隐私政策（Cloudflare）](https://www.cloudflare.com/privacypolicy/)及适用的数据处理条款。我们仅为本政策说明的同步、推送和运行维护目的使用这些服务，不出售这些数据，也不把它们用于广告或数据经纪业务。

## SnapInsert 照片、账户与订阅

SnapInsert 使用配对设备持有的密钥进行端到端加密。照片在 iPhone 的待发内存队列中暂存，不自动存入系统相册；中转服务仅在内存中转发密文，不把照片写入服务器磁盘，也不记录照片内容。服务端能够处理连接地址、密文大小、传输时间和调度等必要元数据，不能据此声称整个服务不记录数据。

Mac 收到后在本机解密、生成预览并写入系统剪贴板；开启辅助功能授权时可向目标应用发出粘贴指令。目标应用、系统剪贴板及其跨设备同步可能保留图片，取决于相关系统设置和应用行为。移除配对或退出 Codex Buddy 不会撤回已经粘贴的图片，也不会自动清空系统剪贴板。

为执行账户额度与购买权益，iOS 端向授权服务发送 Apple 签名的 AppTransaction，以及适用的订阅交易。服务校验签名后，用运行环境与 AppTransaction 的账户关联标识 `appTransactionID` 生成 SHA-256 账户摘要；这不是读取你的 Apple Account 邮箱、姓名或 iCloud 登录密码。App Store 的购买账户可能与设备用于 iCloud 的账户不同，额度依据 Apple 验证的 App Store 账户关联标识执行。

账户账本持久保存账户摘要、运行环境、配对 room 摘要、已验证邀请码的授权组标识（如适用）、当前计数月份、已使用免费张数、当月传输 UUID（用于防重放），以及适用的订阅签名时间、到期时间、交易 ID、原始交易 ID和撤销状态。它不保存原始 AppTransaction、订阅交易或服务器通知的签名原文，也不保存照片、配对密钥、账户邮箱或密码。订阅交易 ID 仍是关联标识；账户摘要不代表记录已完全匿名。

普通账户按北京时间自然月享有 100 张免费额度，于每月 1 日重置。服务在转发前写入计数；一次已消费的传输重试可能仍占用该次额度，计数不等同于目标应用已成功粘贴的图片数。已验证邀请码或有效订阅提供不限张数的授权，服务仍按共享中转容量排队。邀请码账本保存代码摘要、room 绑定、授权与并发配置及聚合密文流量，不保存邀请码原文。

订阅通过 Apple StoreKit 提供，由 Apple 处理付款。购买前以 App Store 显示的价格、周期及条款为准；可在 Apple 的订阅管理中取消自动续订。服务可能接收 Apple 的签名服务器通知以更新续订、到期与撤销状态。恢复购买会重新读取 Apple 权益并请求服务端校验。清空队列、移除配对、清除本机数据或卸载应用不会取消订阅，也不会自动删除账户、计数、邀请码或交易关联记录；目前未承诺统一自动到期时间或自助远端删除入口。有关查询或删除请求，请通过本页联系入口发起，不要在公开 Issues 贴出交易签名、配对信息或邀请码。

## CloudSpace 自有 gateway

CloudSpace 未配置时展示公开的 [iCloud 工作区部署方法](https://github.com/DanielPro0706/codex-icloud-workspace)。配置后，内嵌 Apple WebKit 浏览器访问你填写的 gateway 网页；地址仅保存在当前设备的应用偏好中。应用不内置开发者个人 gateway 地址、认证凭据或私人文件，未配置也不会访问开发者的私人工作区。

网页登录、文件列表、下载、编辑、上传、同步及运行日志由你选择的 gateway 和其后端处理，适用该部署的配置与数据政策。WebKit 使用持久网页数据存储，可在设备上保存登录 Cookie、网站数据和缓存。移除 gateway 地址不会自动清除全部 WebKit 网站数据，也不会删除 gateway 或 iCloud 中的文件。私有网络 gateway 还可能需要用户自行连接 Tailscale 等网络服务；Codex Buddy 不代替这些服务完成网络认证。

## 系统权限

- **文件夹授权（Mac App Store）**：读取你选择目录中的 Codex 额度事件；移除授权后不能继续读取该目录。
- **本地网络**：连接你配对的 Mac。局域网直连使用 HTTP 和访问令牌；请仅在可信网络中使用，并保护配对二维码及令牌。
- **相机（iPhone/iPad）**：实时扫描配对二维码，并为 SnapInsert 拍摄照片。扫码画面不保存；用户选择发送的照片按上述加密传输流程处理。
- **辅助功能（Mac）**：在你授权后向目标应用发出 SnapInsert 粘贴指令；关闭时仍可手动粘贴。
- **推送及实时活动**：在系统允许的情况下刷新后台状态、锁屏或灵动岛。系统设置和刷新预算可能限制更新；关闭实时活动不会删除已有服务端记录。

## 保存、清除与停止处理

本机额度缓存会被较新的快照替换。iOS limitis 中的“清除 limitis 本机数据”只清除该功能的本机配对信息、快照和同步密钥，停止实时活动，并通知 Apple Watch 清除本地副本；不清除 SnapInsert 配对或 CloudSpace 网站数据。仅“断开连接”只移除本机的 Mac 配对，不等同于清除云端或推送服务数据。

CloudKit 保存最新状态，而不是由应用主动维护的一份历史额度列表；可使用 Apple 提供的 iCloud 数据管理功能管理适用的应用数据。仍在运行的 Mac 可能再次同步新数据。

开发者推送服务会用新快照替换同一同步标识下的旧快照；Apple 返回 token 无效时，服务会移除相应 token。现版本未提供用户可直接调用的服务端删除入口，也未设置对所有快照和路由记录统一生效的自动到期时间。清除本机数据、卸载应用或关闭通知不会自动删除 D1 中已有的记录。

要停止后续应用数据发送，请退出 Mac 端，并停止相关设备上的同步使用；也可撤销文件夹、本地网络或实时活动等相应系统授权。已发送的 CloudKit、服务端和提供商运行记录需要分别处理，不能把本机清除操作理解为远程删除。

如需查询、纠正或请求删除开发者服务中的相关数据，请先通过 [GitHub Issues](https://github.com/DanielPro0706/Codex-Buddy-macOS/issues)发起不含敏感信息的请求，开发者会说明进一步核验和处理方式。Issues 是公开页面，请勿提交配对二维码、访问令牌、同步密钥、APNs token、对话日志或账号凭据；本政策不承诺尚未实现的自动删除接口或处理时限。
